# Talent Passport PDF documentation

This directory documents the backend-owned professional Talent Passport PDF.

- `architecture.md` — audit of existing infrastructure and the selected backend-only generation architecture.
- `implementation-plan.md` — file-level implementation plan written before feature changes.
- `design-system.md` — template tokens, typography, color, grid, motif and brand asset rules.
- `pagination.md` — page composition and pagination rules.
- `generation-service.md` — service interface and generation pipeline.
- `templates-and-versioning.md` — official template versions and archived snapshots.
- `document-integrity.md` — references, hashes, revisions and verification records.
- `privacy-and-security.md` — editions, authorization, storage and audit rules.
- `verification.md` — public verification behavior.
- `deployment.md` — dependencies, fonts, deployment and rollback.
- `print-reliability.md` — A4 geometry, print checks and viewer guidance.
- `troubleshooting.md` — generation and rendering failure diagnosis.
- `final-engineering-report.md` — factual final report with executed tests only.

A statement is marked verified only when the exact command and observed result
are recorded in `final-engineering-report.md`.
